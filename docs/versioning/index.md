# Versioning Documentation

This directory contains version tracking and history for Aeturnis Online.

## Files

### [VERSIONS.md](./VERSIONS.md)

Current version information, compatibility matrix, and next release
requirements.

### [VERSION_HISTORY.md](./VERSION_HISTORY.md)

Complete version history with detailed changelogs for each release.

## Current Version

- **Production**: v1.0.0 "Jörmun"
- **Development**: v1.1.0-dev "Jörmun"
- **Codename**: Jörmun (Foundation)

## Versioning Strategy

We follow semantic versioning aligned with implementation phases:

- **v1.0.0**: Foundation & Infrastructure
- **v1.1.0**: Banking & Account Systems
- **v1.2.0**: Combat & Skills
- **v1.3.0**: Characters & Items
- **v1.4.0**: NPCs & Economy
- **v1.5.0**: Social & Polish

Note: The root directory also contains VERSIONS.md and VERSION_HISTORY.md for
quick access during development.
